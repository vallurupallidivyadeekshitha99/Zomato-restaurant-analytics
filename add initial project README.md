# Zomato-restaurant-analytics

About this project:

This is my first end-to-end data analytics project. I am using zomato restaurant listing data to explore restaurant ratings, pricing, cuisines and locations to identify that influences restaurant ratings, which markets have the most competition, and where business opportunities may exist.

Project Goals:

Learning data cleaning using Python & Pandas.

Practice SQL for business analysis.

Build an interactive dashboard using Power BI.

Communicate data-driven insights through visualizations & recommendations.

Tools:

Python

SQL

Power BI

Git & Github

Project Status:

Currently setting up the project and learning the data analysis workflow.

Business Questions:

Which cities have the most listed restaurants?

How are restaurant ratings distributed?

Which cuisines are most common?

How do ratings vary across price range?

Are vote counts associated with restaurant ratings?
